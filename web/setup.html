    OBS

    สร้าง scene yokoten-ocr ที่มีเฉพาะ source การ์ด กับ filter yokoten-crop ตามกรอบ subtitle ของโปรไฟล์ แล้วใน scene ที่เป็น Program ตอนกด ใส่ Yokoten overlay (/overlay เต็มเฟรมบนสุด) กับ Yokoten card audio (เสียงการ์ดแบบ Monitor Only) และปิดเสียง Mic/Aux ทุกตัว ยกเว้น input ที่ใช้เสียงจากการ์ดอยู่แล้ว กดซ้ำได้ ไม่ลบ ไม่เปลี่ยนชื่อ ไม่แตะ source อื่น และไม่เปิดเสียง Mic/Aux คืน

    Discord Go Live

    แชร์ภาพ Program ของ OBS ผ่าน Windowed Projector เพื่อนเห็นเกมพร้อมแถบไทยและได้ยินเสียงเกมจาก monitoring เสียงพูดเข้า Discord ทางไมค์ของ Discord Yokoten ไม่เปิดหรือตรวจ projector ให้
